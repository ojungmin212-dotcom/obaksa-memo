# 오박사의 메모장

어디서든 주소 하나로 열리는 칠판 메모장. 인터넷 없이도 쓰고, GitHub 비공개 저장소로 기기끼리 맞춥니다.

## 1. 열기와 홈 화면 아이콘
- 주소: **https://ojungmin212-dotcom.github.io/obaksa-memo/**
- **PC 크롬·엣지**: 주소창 오른쪽 설치 아이콘 → 설치. 바탕화면·작업표시줄에 아이콘이 생깁니다.
- **안드로이드 크롬**: 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가.
- **아이폰 사파리**: 공유 버튼 → 홈 화면에 추가.
- 한 번 열고 나면 인터넷이 없어도 열립니다.

## 2. 기기끼리 맞추기 (GitHub 동기화)
처음 한 번만 준비하고, 각 기기에서 설정에 같은 값을 넣으면 됩니다.

1. 비공개 저장소 `obaksa-memo-data` 는 이미 만들어 두었습니다: https://github.com/ojungmin212-dotcom/obaksa-memo-data
2. GitHub 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Repository access: **Only select repositories** → 방금 만든 저장소 하나만.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - 만료 기간은 1년 정도로 정하고, 만료되면 새로 만들어 넣으면 됩니다.
3. 메모장 오른쪽 위 설정 → GitHub 동기화에 아이디, 저장소 이름, 토큰을 넣고 **연결**.
4. 다른 기기에서도 3번만 하면 같은 메모가 보입니다.

동기화 방식:
- 적는 즉시 그 기기에 저장되고, 5초 뒤 저장소로 올라갑니다. `Ctrl+S` 로 바로 올릴 수도 있습니다.
- 앱을 열 때, 다시 볼 때, 3분마다 저장소에서 새 내용을 받아옵니다.
- 같은 메모를 두 기기에서 고치면 나중에 고친 쪽이 남습니다.
- 저장소에 저장할 때마다 커밋이 남아서 GitHub에서 예전 내용을 찾아볼 수 있습니다.
- 토큰은 각 기기 브라우저에만 저장됩니다. 그 저장소 하나만 다룰 수 있는 토큰이라 다른 저장소는 안전합니다.

## 3. 비밀 메모 (암호화)
- 메모의 자물쇠 버튼을 누르면 처음에 **비밀번호**를 만듭니다. 모든 기기에서 같은 비밀번호를 씁니다.
- 잠근 메모는 AES-256 으로 암호화되어 기기와 GitHub 양쪽에 **암호문으로만** 저장됩니다.
- 처음부터 비밀로 적으려면 입력칸 옆 자물쇠를 켜고 적으세요. 평문이 저장소에 한 번도 올라가지 않습니다.
- 평범한 메모를 나중에 잠그면, 잠그기 전 내용이 저장소의 예전 커밋 기록에 남아 있을 수 있습니다.
- 5분 동안 안 쓰면 자동으로 다시 잠깁니다 (설정에서 바꿀 수 있음).
- **비밀번호를 잊으면 잠근 메모는 되살릴 수 없습니다.**

## 4. 일정 알림
- 일정을 고르고 날짜·시간을 넣으면 오른쪽(폰은 위쪽) **다가오는 일정**에 모입니다. 지난 일정은 빨간색.
- 앱이 열려 있으면 정한 시간 전에 알림이 뜹니다 (설정에서 정각/5/10/30/60분 전).
- 앱이 꺼져 있어도 꼭 울려야 하는 일정은 편집 화면의 **캘린더에 추가** → 구글 캘린더 또는 .ics 파일.

## 5. 단축키 (F1 로도 볼 수 있음)
| 키 | 동작 |
|---|---|
| Ctrl+N (브라우저 탭에서는 Alt+N) | 새 메모 |
| Enter / Shift+Enter | 저장 / 줄바꿈 |
| Ctrl+F | 찾기 |
| Ctrl+S | 저장하고 바로 동기화 |
| ↑ ↓ | 메모 고르기 |
| F2 / Enter | 고른 메모 고치기 |
| Space | 할일·일정 완료 체크 |
| Delete | 휴지통으로 |
| Ctrl+Z | 방금 지운 메모 되살리기 |
| Ctrl+; / Ctrl+Shift+; | 오늘 날짜 / 지금 시각 넣기 (엑셀과 같음) |
| Ctrl+V | 사진 붙여넣기 |
| Esc / Ctrl+Enter | 고치기 끝내기 |

크롬 브라우저 탭에서는 Ctrl+N 이 새 창 열기로 먼저 잡힙니다. 설치한 앱 창에서는 그대로 쓰거나 Alt+N 을 쓰세요.

## 6. 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 칠판·글라스 테마 |
| `app.js` | 메모, 사진, 암호화, 일정, 단축키, GitHub 동기화 |
| `sw.js` | 오프라인 실행 (서비스 워커) |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘 |
| `기획초안.md` | 기획 질문, 답변, 설계 결정 (내 PC에만 보관, 저장소에는 올리지 않음) |
| `old/artifact-v1.html` | 1차 버전 (Claude 아티팩트용) |

## 7. 고친 뒤 다시 올리기
앱 파일을 고친 뒤 GitHub Pages 저장소에 올리면 끝입니다. `sw.js` 맨 위 `CACHE` 이름의 숫자를 하나 올려두면 모든 기기가 새 버전을 확실히 받습니다.

## 8. 내 PC에서 미리 보기
```bash
python -m http.server 5180 --bind 127.0.0.1
```
브라우저에서 http://localhost:5180 을 엽니다.
